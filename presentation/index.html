The Challenge

Why Is This Problem Hard?

📸

Tiny Labeled Dataset

Only ~810 annotated training images from CCTV — real-world annotation is costly

🚗

Domain-Shifted Classes

13 vehicle types — CNG, rickshaw, easy-bike, leguna — absent from COCO/Cityscapes

🌧️

Harsh Conditions

Occlusion, monsoon/fog/night, low-res CCTV, dense mixed-lane traffic

💡 Key Constraint

All images are 1280×720 from 4 CCTV clips. Frames 1–2 apart → near-duplicates. Random splits leak. We use temporal-aware per-clip splits throughout.

Approach 1 — What Didn't Work

Naïve Baseline: Random Split + Overfit

Pub: 0.3896

YOLOv8-Large, Random Split

First attempt: YOLOv8-L (43M params), random 80/20 split, 200 epochs @ 960px, conf=0.25.


Problems:

• Data leakage — frame N in train, N+1 in val → inflated local scores

• High conf=0.25 → missed many objects (mAP cares about ranking, not threshold)

• 43M params on 810 images → severe overfitting

• No ensembling, single model only

Data Leak High Conf Overfit

🔑 Lesson

Bigger model ≠ better on small data. Split strategy and inference conf matter more than model size.

Approach 2 — Building the Foundation

Smart Baseline: Temporal Split + Right-Sized Model

Priv: 0.5512

YOLO11s, Leak-Free Split

Switched to YOLO11s (9.4M — 4.6× smaller) with temporal-tail split: last 12% of frames per clip → validation.


Fixes applied:

• Temporal split → no near-duplicate leakage

• Right-sized model for 810 images

• Ultra-low conf=0.001 → full recall for mAP

• COCO pretrained weights → transfer learning

Leak-Free YOLO11s Transfer Learning
⚠️ TTA Pitfall

Running this 960-trained model at 1280px + TTA → dropped to 0.5331 public. Feature maps calibrated to training resolution — never mismatch.

Approach 3 — Ensemble Power

K-Fold Ensemble with Weighted Box Fusion

Priv: 0.6278

5-Fold YOLOv8s + WBF

Trained 5 YOLOv8s models using per-clip temporal k-fold splits. All 5 predict on each test image, boxes fused with WBF.


Key innovations:

• Per-clip array_split → every fold sees all 4 cameras

• WBF averages overlapping boxes (vs NMS pick-one)

• Single fold avg mAP ~0.44, but ensemble 0.5675 pub → WBF gives real boost

• Private 0.6278 — much higher than public 0.5675

Architecture Exploration

RT-DETR: Transformer Experiment

Priv: 0.5069

RT-DETR-L (Transformer)

Tested RT-DETR-L, an NMS-free end-to-end transformer detector as an architectural diversity experiment.


Why it underperformed:

• Training interrupted at epoch 49/70 (~70%)

• Transformers are data-hungry — 810 images too small

• CNN inductive biases (locality, translation equivariance) better at this scale

• No k-fold, no WBF — single incomplete model

RT-DETR: Confusion Analysis

Transformer Class Confusion

Analysis of RT-DETR validation confusion matrix highlights the core limitations of the model on small data:


• High Background Confusions: Significant number of vehicle boxes classified as background due to incomplete training.


• Similar-Class Errors: Confusing trucks and buses, or cars and microbuses, due to lack of distinct feature extraction at early epochs.

Approach 4 — Best Private Score ★

Hi-Res 5-Fold: YOLO11m @ 1280px — Private 0.6454

★ 0.6454

5-Fold YOLO11m @ 1280 + WBF + TTA

Scaled up: YOLO11m (20M params) trained natively at 1280px. 5-fold temporal split, WBF + TTA inference.


Why it's the best private score:

• Native 1280px training → features calibrated to actual resolution

• 5 folds → maximum diversity in ensemble

• mixup=0.1 for regularization

• 40 epochs × 5 folds in ~6.3h on T4

Public LB ≠ Private LB ranking. 3-fold looked better publicly (0.6381 vs 0.6033) but 5-fold won privately (0.6454 vs 0.6252). More folds = more diversity = better generalization.

Approach 5 — Best Public Score

Hybrid Pipeline: VisDrone + SAHI + WBF

Pub: 0.6456

VisDrone Pretrain → K-Fold → SAHI+TTA+WBF

Phase 1 — Domain Pretrain: VisDrone 2019 aerial dataset (30% subset, 15 ep @ 640px) → dense traffic priors


Phase 2 — Fine-Tune: 3-fold @ 1280px, 80 epochs, AdamW, backbone freeze, copy_paste=0.3, perspective warp


Phase 3 — Inference: Standard TTA + SAHI (512×512 tiles, 30% overlap) + WBF fusion

VisDrone SAHI WBF+TTA

Why SAHI Helps

Distant vehicles = 10–20px tiny objects. SAHI tiles the 1280×720 image into overlapping 512×512 slices — effectively zooming in on what full-image inference misses.

Takeaways

Key Lessons Learned

✅ What Worked

  • Temporal-aware splits — prevented data leakage from near-duplicate CCTV frames
  • K-Fold + WBF ensemble — consistently better than any single model
  • Native hi-res training (1280px) — train at the resolution you infer at
  • Ultra-low conf (0.001) — mAP cares about ranking, not absolute confidence
  • VisDrone domain pretraining — aerial traffic priors transfer well
  • SAHI for tiny objects — catches distant vehicles others miss

❌ What Didn't Work

  • Random splits — inflated local mAP via temporal leakage
  • Train/infer resolution mismatch — 960-train at 1280-infer regressed
  • RT-DETR transformer — too data-hungry for 810 images
  • Overparameterized models — YOLOv8-L overfitted on small data
  • Equal-weight merge — weaker models dilute stronger ones
  • Trusting single-fold grid search — noisy, doesn't generalize
